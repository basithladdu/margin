Claude Code · my-app
why does the login page sometimes log me out?

Short answer: your session cookie and your access token expire at different times, and the page only checks one of them.

Here's what happens. When you sign in, the server sets a cookie that lives for 7 days, but the access token inside it lives for only 15 minutes. The refresh call that should swap in a new token runs only when you navigate, so a tab left open for a while ends up holding a dead token.

The next request fails with a 401, and the error handler treats every 401 as "signed out". That's the logout you're seeing.

Three ways to fix it, from smallest to sturdiest:

  • Refresh the token on a timer, a minute before it expires.
  • Retry once on a 401 after refreshing, before giving up.
  • Move the refresh into the API client so every call is covered.

I'd go with the third. It's about twenty lines in api.ts and it covers the cases the other two miss, like a laptop waking from sleep.

Margin

Read long replies without losing the thread

Claude's answers are good and long. Margin gives you a pen and a bookmark, right in the app.

🖍️

Highlight in colour

Yellow, green, pink. Select, press, done. Press it again or use Erase to take it off.

✎

Notes on the side

Pin a one-line note to any highlight. It shows under the paragraph and in your notebook.

📍

Read up to here

Drop a marker where you stopped. Resume shows everything after it. Clear it when you're done.

✏️

Sketch an idea

A small sketch pad in the side pane. Strokes are smoothed into clean SVGs with perfect-freehand.

📓

A notebook you can browse

Every highlight, note and sketch lands in Documents/Margin Notebook: a searchable page plus Markdown for Obsidian or Logseq.

🔒

Yours, on your machine

No account, no server, no tracking. It's a few files on your computer and you can read every line.

Install

You need Claude Code (the desktop app's Code tab or the terminal). Then:

In a terminal, add the marketplace and install 
claude plugin marketplace add basithladdu/margin
claude plugin install margin@margin
Or from inside Claude CodeType this at the prompt in a terminal session, say y, then pick a scope: 
/plugin install margin --marketplace basithladdu/margin
Start a new sessionThe Margin row appears above the prompt. Select text in a reply and press a colour. Type /margin to open your notebook.

The honest list

  • A paragraph with a highlight in it is redrawn by Margin, so bold and inline code in that paragraph show as plain text. Everything else looks exactly as Claude wrote it.
  • The desktop app doesn't let mods scroll the conversation, so Resume opens the rest of your reading in the side pane instead of jumping.
  • Mods are a new part of Claude Code. If an update changes them, Margin may need an update too.
  • Highlights belong to the computer you made them on. Back up Documents/Margin Notebook if you care about them.
